# CyberSpine 项目立项与全景白皮书 (Project Proposal & Vision Whitepaper)

**项目名称**：CyberSpine (赛博脊椎)  
**项目代号**：Project CyberSpine  
**版本定义**：v2.1 架构终稿（双 Agent 协同 + 本地微型哨兵 + 开放插件生态）  
**核心定位**：为桌面 AI 智能体打造的开放式仿生中枢神经微内核与 MCP 感觉门控中间件

---

## 1. 行业背景与范式转移

### 1.1 从“割裂工具”到“双 Agent 协同生态”的跃迁
当前前沿 AI 大模型（如 Antigravity, Claude, Codex, GPT-4）已经在**“前额叶认知与理性大脑”**上取得了巅峰级的进展，同时它们自身已经具备极强的**“双手（命令行操作、代码编写、工具调用）”**。

然而，AI 目前依然是一个“**漂浮在云端、失去身体感官的裸脑**”。在操作系统层面：
* 缺乏统一的中枢神经将底层的**视觉、听觉、外设触觉与系统内脏状态**进行汇聚融合；
* 缺乏端侧轻量级的**感觉门控（Sensory Gating）**，导致直接调用大模型要么成本高昂、要么频繁无效打扰。

### 1.2 本质解密：构建一个本地专职的“微型哨兵 Agent”
**CyberSpine 的本质不是重新造一个庞大的大模型，而是在本地构建一个专职的“微型哨兵 Agent（Mini Sentinel Agent）”**：
1. **微型哨兵 Agent (CyberSpine)**：负责 24 小时在端侧值班站岗，统筹底层感官插件，利用本地 3B SLM 进行感觉门控（过滤 99.9% 噪音与脱敏）；
2. **战略总指挥 Agent (Master Agent)**：拥有强大的执行双手，平时按需休眠，仅在接收到哨兵上报的高价值神经信号时主动出击；
3. **向上标准接口 (MCP)**：通过行业标准 **Model Context Protocol (MCP)** 连接哨兵与主脑；
4. **向下开放插件 (Plugin SDK)**：让全球开发者自由编写和选配 AI 的**眼睛（视觉插件）、耳朵（听觉插件）、触觉（IO插件）与内脏（系统文件插件）**！

## 2. 核心设计哲学 (Design Philosophy)

### 原则一：类脑分层与双 Agent 协同 (Dual-Agent Collaboration)
* **前哨兵 vs 司令部**：微型哨兵 Agent 专精于“毫秒级感知与噪音门控”；战略主脑 Agent 专精于“深度推理与工程执行”。
* **大脑自有双手**：高级 Agent 自身具备强大的 Tool Calling 执行力，脊髓不需要重复包揽所有业务，专注于“多模态感知整合与反应式上报”。

### 原则二：自由选配与极致隐私 (Composable Embodiment & Privacy)
* **用户拥有完全的选配权**：用户可以像组装电脑一样组装 AI 的感官——需要极高隐私时只加载“触觉（USB）与内脏（文件）”插件，关闭摄像头与麦克风插件；需要游戏陪伴时加载“视觉（屏幕）与听觉”插件。
* **原始数据不出本地**：任何插件捕获的声音和画面，均在本地 3B 模型闭环消化提炼，绝不上传原始媒体流。

### 原则三：极高信噪比感觉门控 (Sensory Gating & Anti-Fatigue)
* 仿生人类神经系统的无意识生理机制：在主动介入呼吸前，呼吸由小脑自主维持；人类不会时刻感受袜子触感。CyberSpine 确保只有在发生高置信度重大事件时，才通过 MCP 唤醒主脑。

## 3. 典型应用场景与跨模态协同旅程 (Multimodal User Scenarios)

### 场景 A：跨模态协同：视频剪辑项目挂载
1. **✋ 触觉插件**：捕获到相机高速存储卡插入（WMI 设备即插即用）；
2. **👀 视觉插件**：检测到用户当前前台窗口切换到了 Premiere Pro / 剪映；
3. **🫀 内脏插件**：识别到存储卡内包含多个 4K MOV 视频流；
4. **🧬 哨兵 Agent 脊髓融合**：三路感官信号在本地 3B 模型汇聚，生成极高置信度的情境判定：`用户正在准备导入相机拍摄素材进行剪辑`。
5. **🧠 大脑与化身响应**：通过 MCP 激活高级 Agent 与桌面 Miku，主动为用户执行素材按拍摄日期分类与轻量代理文件预生成！

---

### 场景 B：异常排错与开发辅助
1. **🫀 内脏插件**：捕获到剪贴板变更为长篇报错堆栈；
2. **👀 视觉插件**：检测到用户正在 VSCode 中编辑对应的 Python 模块；
3. **🧬 哨兵 Agent 感觉门控**：过滤常规复制噪音，精准判定为“研发中的定位排错”；
4. **🧠 大脑接管**：高级 Agent 自动根据当前上下文准备好修复方案并主动提示。

## 4. 关键效能指标 (Key Performance Indicators)

| 指标维度 | 目标基准 | 说明 |
| :--- | :--- | :--- |
| **哨兵 Agent 空闲占用 (Idle Resource)** | CPU < 0.1%，内存 < 80MB | 微型 Agent 平时完全事件驱动休眠 |
| **插件生态兼容性 (Plugin Latency)** | 插件事件调度延迟 $\le$ 5ms | 高性能异步总线分发 |
| **跨模态门控推理延迟 (Gating Latency)** | $\le$ 120ms | 本地 3B 门控模型特征融合推理耗时 |
| **事件过滤准确率 (Precision)** | $\ge$ 95% | 跨模态校验大幅降低单点误报率 |
