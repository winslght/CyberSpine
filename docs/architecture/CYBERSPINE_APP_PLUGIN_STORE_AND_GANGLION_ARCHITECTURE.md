## 2. 四大核心系统详细设计

### 支柱 1：独立原生桌面 APP 与 GUI 驾驶舱
* **技术选型**：
  * 基于现代响应式轻量引擎（PyQt6 / Modern WebView + Tailwind / Glassmorphism UI 架构），保证极低内存开销与原生硬件加速；
* **五大功能面板**：
  1. **神经脉冲驾驶舱**：动态呈现当前 5s 心跳节律波形、8 通道实时电位图、60s 世界简报时间轴；
  2. **神经插件商店 (Plugin Store)**：模块化展示官方与社区插件，支持一键安装、更新、启用与热拔插；
  3. **端侧小模型管理中心 (SLM Hub)**：集成 Ollama / llama.cpp，支持一键拉取 Qwen2.5-3B、Llama-3.2-3B 等，实时显示显存占用与每秒 Token 速度；
  4. **上级大脑连接器**：用户可配置连接云端大模型 API（Claude、OpenAI、DeepSeek 等）或本地 IDE 伴侣总线；
  5. **双向神经递质与抑制监控**：可视化展示当前系统的兴奋阈值、免打扰冷却倒计时（如 300s/900s 抑制进度条）与手动一键激活/静音。

---

### 支柱 2：插件化神经末梢标准协议 (Biomimetic Plugin Store)
每个神经末梢均被封装为标准的独立插件包：
```
plugin_package/
├── manifest.json       # 插件元数据 (名称/版本/支持通道/作者/所需权限)
├── receptor_entry.py   # 继承 BasePerceptor 的探针入口
├── requirements.txt    # 专用轻量依赖
└── icon.png            # 插件商店展示图标
```
* **热插拔加载器 (`PluginLoader`)**：支持在 APP 运行期间动态加载、卸载或重载任意神经末梢，无需重启中枢守护进程。

---

### 支柱 3：分脑多核分岔协同网络 (Distributed Multi-Ganglion Network)
打破“单模型包打天下”的瓶颈，采用仿生生物分脑架构：
1. **👁️ 视觉神经节 (Visual Ganglion)**：
   * 专职运行轻量视觉多模态小模型（如 Qwen2-VL-2B）；
   * 专职对接屏幕视觉、窗口截图、OCR 神经末梢，仅在画面发生显著语义变动时激活；
2. **👂 听觉神经节 (Auditory Ganglion)**：
   * 专职运行极速端侧音频小模型（如 Whisper-tiny / SenseVoice）；
   * 专职监听麦克风、系统音频流与语音唤醒词；
3. **🦾 躯体外设神经节 (Somatic Ganglion)**：
   * 专职运行毫秒级 IO、前台焦点、高负载、网络与崩溃监听探针；
4. **🧬 中脑多模态融合中枢 (Midbrain)**：
   * 将视觉、听觉、躯体三大分岔送来的多模态信号进行时空对齐，消除冗余，生成统一的《1分钟多模态世界简报》。

---

### 支柱 4：全链路双向刺激与下行抑制神经递质系统
* **上行兴奋刺激 (Excitatory Pathways)**：
  * **常规节律**：5s 微观心跳 $\rightarrow$ 60s 宏观简报；
  * **紧急快速通道 (Fast-Path Interrupt)**：突发严重崩溃、高压超限或硬件接入时，跨过 60s 窗口毫秒级直接叩响高级大脑；
* **下行抑制递质 (Inhibitory Pathways)**：
  * 大脑处理完任务后，向中枢下发抑制递质（如 `SUPPRESS_AND_OBSERVE`）；
  * 中枢进入免打扰稳态（300s 定向设备抑制 / 900s 用户拒绝退避），实现真正的高情商伴侣体验。
