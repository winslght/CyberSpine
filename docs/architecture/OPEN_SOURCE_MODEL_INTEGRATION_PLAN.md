### 💡 为什么 Ollama 是当前全球最优解？
1. **开箱即用，无需编译**：Windows 下双击 `OllamaSetup.exe` 安装即可常驻系统，不用在 Python 里折腾复杂的 C++ / CMake 编译环境（如 `llama-cpp-python` 的各种 DLL 缺失报错）；
2. **完美释放硬件性能**：当前物理机配备 **NVIDIA GeForce RTX 4060 Laptop GPU**，Ollama 会自动检测 CUDA 驱动，将 `Qwen2.5-3B` 纯 GPU 加速推理，速度可达 **80~120 Token/s**，生成动作指令只需不到 100ms；
3. **原生支持 JSON 语法约束**：调用 Ollama API 时传入 `format: "json"`，模型 100% 吐出标准 JSON，杜绝胡言乱语；
4. **模型一键下载管理**：在 CyberSpine 驾驶舱中可直接调用 Ollama 的 `/api/pull` 接口，无缝实现“模型商店一键下载”。

## 3. 下一步模型接入实施规划

1. **Step 1 (Ollama 服务一键安装与接管)**：
   * 指引/提供脚本下载官方 Windows `OllamaSetup.exe`；
   * 启动本地 `http://localhost:11434` 服务并拉取 `qwen2.5:3b` 或 `qwen2.5:1.5b`。
2. **Step 2 (CyberSpine 真实模型驱动对接)**：
   * 将 `src/models/local_engine.py` 升级为真实调用 Ollama `/api/generate` 与 `/api/chat`；
   * 注入结构化 System Prompt 与当前 8 大感官状态，由真实神经网络生成动作推演。
3. **Step 3 (实机全链路实测)**：
   * 实测真实神经网络推演动作、安全审批放行与 VSCode/电源控制闭环。
