# CyberSpine 最小闭环 Demo

## 目标

验证本地 Windows 感知是否能安全地生成有用的上下文，供上层 AI Agent 通过 MCP 读取，并在用户确认后执行一项有限动作。

## 范围

### 必须具备

1. 采集前台应用、窗口标题和基础系统状态（CPU、内存、网络）。
2. 以稳定、可序列化的 JSON 输出当前上下文。
3. 通过一个 MCP 工具提供该上下文：`cyberspine_get_current_context`。
4. 仅在用户明确确认后执行一项低风险动作：在 VS Code 或资源管理器中打开指定工作区。
5. 记录每次上下文读取、动作提议、确认与执行结果。

### 明确不在本阶段

- 自动执行或主动打扰用户；
- 插件商店、11 路感官全覆盖、AIDA64 深度硬件遥测；
- 本地模型拉取、模型热切换和复杂推理；
- 8 页驾驶舱作为功能验收前提。

## 验收标准

1. 在未安装 Ollama、未启动驾驶舱的机器上，Demo 仍可启动。
2. MCP 客户端能读取一份合法 JSON 上下文。
3. 动作未获确认时，系统不改变用户文件、系统设置或窗口状态。
4. 用户确认后，只执行文档指定的单一动作，并返回结构化结果。
5. 核心 Demo 测试可在干净虚拟环境中重复执行。

## 扩展原则

每项新感知或动作必须：接入这条闭环、声明隐私边界、通过安全门控，并附带可复现测试。
